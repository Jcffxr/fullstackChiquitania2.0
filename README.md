# fullstackChiquitania2.0

Una plataforma web moderna para impulsar el desarrollo sostenible y la innovación tecnológica en la región Chiquitana.

## 🌟 Características

- **Diseño Responsivo**: Optimizado para dispositivos móviles, tablets y escritorio
- **Interfaz Moderna**: UI/UX profesional con animaciones suaves y efectos hover
- **Navegación Intuitiva**: Menú fijo con scroll suave entre secciones
- **Formulario de Contacto**: Sistema de notificaciones y validación de datos
- **Rendimiento Optimizado**: Código limpio y eficiente sin dependencias pesadas

## 🚀 Secciones del Sitio

1. **Inicio**: Hero section con presentación del proyecto y llamados a la acción
2. **Sobre Nosotros**: Misión, visión y valores de la organización
3. **Servicios**: 6 servicios principales (Desarrollo Web, Apps Móviles, Gestión de Datos, etc.)
4. **Proyectos**: Showcase de proyectos destacados con etiquetas
5. **Contacto**: Formulario funcional con información de contacto y redes sociales

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Diseño responsive con Flexbox y Grid
- **JavaScript (Vanilla)**: Interactividad sin frameworks adicionales
- **Font Awesome**: Iconografía profesional

## 💻 Uso Local

1. Clonar el repositorio:
```bash
git clone https://github.com/Jcffxr/fullstackChiquitania2.0.git
cd fullstackChiquitania2.0
```

2. Abrir `index.html` en tu navegador o usar un servidor local:
```bash
# Con Python 3
python3 -m http.server 8080

# Con Node.js (http-server)
npx http-server
```

3. Visitar `http://localhost:8080` en tu navegador
